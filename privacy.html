개인정보처리방침

시행일: [시행일]

플롯노트는 이용자의 개인정보를 수집하거나 별도 서버에 저장하지 않습니다. 이 방침은 플롯노트가 이용자 정보를 어떻게 다루는지 설명합니다.

1. 수집하는 개인정보

플롯노트에는 회원가입이 없고, 이용자 정보를 받아 두는 서버도 없습니다. 운영자는 이용자의 개인정보나 작성한 글을 수집하지 않으며, 볼 수도 없습니다.

2. 글과 데이터가 저장되는 곳

  • 이용자가 쓴 글, 보드, 기록, 설정은 이용자 기기의 브라우저 저장소에 저장됩니다.
  • 구글로 로그인하면, 같은 데이터가 이용자 본인의 구글 드라이브에 있는 플롯노트 전용 숨김 폴더(앱 데이터 폴더)에도 저장됩니다.
  • 두 곳 모두 이용자만 접근할 수 있으며, 운영자는 접근할 수 없습니다.

3. 구글 로그인으로 받는 정보

  • 로그인할 때 구글로부터 이메일 주소, 이름, 프로필 사진 주소를 받습니다.
  • 이 정보는 화면에 로그인한 계정을 표시하고, 다른 계정의 글이 섞이지 않도록 확인하는 데만 씁니다.
  • 이 정보는 이용자 기기에만 저장되며 운영자에게 전송되지 않습니다.
  • 구글 드라이브 권한은 플롯노트 전용 숨김 폴더에만 해당하며, 이용자의 다른 드라이브 파일은 보거나 바꿀 수 없습니다.
  • 플롯노트가 구글 API로 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

4. 제3자 제공 및 처리 위탁

운영자는 이용자의 개인정보를 제3자에게 제공하거나 처리를 위탁하지 않습니다.

5. 이용 중 접속하는 외부 서비스

플롯노트를 열거나 일부 기능을 쓸 때 아래 외부 서비스에 접속하며, 이때 접속 기록(IP 주소 등)은 각 서비스의 정책에 따라 처리됩니다.

  • GitHub Pages: 플롯노트 페이지 제공
  • Google: 로그인, 구글 드라이브 저장, 글꼴(Google Fonts)
  • jsDelivr: 글꼴(Pretendard)
  • Notion: [버그/건의] 버튼을 누를 때만
  • 리틀리(litt.ly): [커피 한 잔 보내기] 버튼을 누를 때만

6. 광고·분석·AI

  • 플롯노트는 광고나 방문 분석 도구를 쓰지 않습니다.
  • 기기의 브라우저 저장소는 글 저장과 설정 기억 등 플롯노트 동작에만 씁니다.
  • 플롯노트에는 AI 기능이 없으며, 이용자의 글을 AI에 보내거나 학습에 쓰지 않습니다.

7. 데이터 삭제

  • 기기에 저장된 데이터는 플롯노트에서 지우거나 브라우저의 사이트 데이터를 삭제하면 지워집니다.
  • 구글 드라이브에 저장된 데이터는 구글 드라이브 설정의 앱 관리에서 플롯노트의 숨겨진 데이터를 삭제할 수 있습니다.
  • 플롯노트의 구글 계정 접근 권한은 구글 계정의 연결된 앱 관리 화면에서 언제든 해제할 수 있습니다.
